絵文字ダス PWA v1.06

v1.03をベースに、連想語辞書による検索拡張を追加した版です。UI・絵文字データ・既存機能は変更していません。

【GitHub Pagesへの配置】
1. ZIPを展開します。
2. index.htmlを含む全ファイルを、GitHub Pagesの公開元フォルダに配置します。
   ZIPそのものではなく、中身をアップロードしてください。
3. 公開されたHTTPSのURLをSafari等で開きます。
4. iPhone・iPadでは共有メニューから「ホーム画面に追加」します。

【初回とオフライン利用】
初回に約11MBのデータを取得します。「?」内に「オフライン準備完了」と表示された後は、検索・比較をオフラインでも利用できます。
iOSのファイルアプリからindex.htmlを直接開く方法ではなく、HTTPS上でご利用ください。

【保存データと公開範囲】
お気に入り・履歴・表示モードはブラウザ内に保存されます。
SitesとGitHub PagesはURLが異なるため、Sites側の保存データは自動では引き継がれません。
通常のGitHub Pagesでは一般公開となり、Sitesの本人限定設定は引き継がれません。

【収録内容】
Unicode Emoji 16.0：3,781種類（代表一覧1,997件、残りはバリエーション）。
日本語検索・連想検索・AND検索・分類・色と形の絞り込み。
端末表示／Google系／比較、コピー、履歴、お気に入り、バリエーションの拡大表示。

【v1.03】
検索枠下の定型語ボタンを削除し、上部・絵文字枠の余白を縮小。
スマホでは通常表示3列、比較表示2列。絵文字自体の大きさを維持。

画像・データの出典と利用条件はlicenses.htmlおよび同梱ライセンスをご確認ください。

【v1.05】
associations.json を追加し、各絵文字の既存キーワードから一段だけ連想語を展開して検索します。
variants.json により代表的な日本語表記ゆれも検索時に吸収します。
従来の簡易連想検索も互換性のため維持しています。
